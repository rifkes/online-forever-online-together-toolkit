# This repo houses all of the template files for the <3 online forever online together <3 5 day workshop

## 1. Download Node.js

- Open a new terminal window and run the following commands

### Download and install nvm:
`curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash`
### in lieu of restarting the shell
`\. "$HOME/.nvm/nvm.sh"`
### Download and install Node.js:
`nvm install 24`
### Verify the Node.js version:
`node -v # `
### Verify npm version:
`npm -v # `

## 2. Set up your project
- Drag and drop your project folder onto the terminal app icon in the dock to open a new terminal in your project folder
- run `npm install`
- run `node index.js`
